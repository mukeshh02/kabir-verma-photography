# Solene - Wedding Photography Theme Local Clone

Complete offline clone of https://solene.qodeinteractive.com/ running on http://localhost:3004.

## Features Cloned:
- **All Core Demos & Layouts**:
  - Main Home (`/`)
  - Photography Studio (`/photography-studio/`)
  - Fullscreen Home (`/fullscreen-home/`)
  - Wedding Photography (`/wedding-photography/`)
  - Carousel Gallery (`/carousel-gallery/`)
  - Horizontal Gallery (`/horizontal-gallery/`)
  - Metro Gallery (`/metro-gallery/`)
  - Gallery Minimal (`/gallery-minimal/`)
  - Interactive Links (`/interactive-links/`)
  - Split Showcase (`/split-showcase/`)
  - Parallax Showcase (`/parallax-showcase/`)
  - Passepartout Slider (`/passepartout-slider/`)
- **Inner Pages**: About Me, About Us, Our Team, Our Services, Our Process, Contact, Contact 2, Shop, Cart, Checkout, My Account, Blog layouts, Portfolio items.
- **Sliders & Animations**: Revolution Slider (`rs6.min.js`, `rbtools.min.js`), Qode Theme Modules (`modules.min.js`, `modules.min.css`), Swiper/Carousels, and smooth scroll transitions.
- **Icon Libraries**: Dripicons, Elegant Icons, FontAwesome, Ionicons, Linea Icons, Linear Icons, Simple Line Icons.
- **Port**: Runs independently on `http://localhost:3004`.
